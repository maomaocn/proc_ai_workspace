**注意：需求一次性确定，编码分 M0~M6 迭代。** 用户输入 `开始 M1 阶段任务`，Codex 按根目录 AGENTS.md 自动读取规范、检查依赖、执行开发与验证；不再重复角色设定。

## 开发协议
- 每次先检查代码、现有未提交变更、阶段依赖和测试证据。
- 只开发当前阶段，禁止提前生成其他阶段空壳；跨阶段共享结构仅在当前阶段实际使用时创建。
- 每阶段有独立 `docs/phases/Mn.md`，含任务、测试、验收、排除项；开发后写 `docs/PHASE_STATUS.md`。
- P0 必须闭环；P1 不可用静态假数据冒充真实运行；P2 不阻塞核心交付。

## 240 学时教学参考（非开发里程碑硬约束）
第1周 M0/M1 Python 按需入门与模型调用；第2周 M1 对话及低代码对照；第3周 M2 RAG；第4周 M3 业务与 Tool Calling；第5周 M4 Workflow；第6周 M5 MCP/Harness；第7~8周 M6 联调、测试、部署和答辩。Python 不被强制设置为独立 30 学时课程，而是在各项目阶段按需教学。
