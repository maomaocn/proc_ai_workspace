# UI 视觉设计规范 V1.1

## 1. 参考边界（强制）
用户提供的截图仅供**视觉风格借鉴**，包括浅米白背景、微弱网格纹理、舒适留白、圆角卡片、浅边框、柔和阴影、适度紫/青色渐变和清晰标题层级。**不得复制截图中的产品名称、业务模块、数据指标、页面文案、卡片内容、信息架构、具体布局组合或交互逻辑。** 本项目的页面功能仅由 FRONTEND_PRD 决定。

## 2. Design Tokens（建议值，可在视觉评审时微调）
```css
:root {
  --bg-page: #F8F7F2;
  --bg-surface: #FFFFFF;
  --bg-muted: #F2F4F0;
  --text-primary: #1F2D28;
  --text-secondary: #64716B;
  --border-subtle: #E6ECE8;
  --brand: #0F766E;
  --brand-hover: #0C615B;
  --ai-accent: #4F46E5;
  --success: #15803D;
  --warning: #A16207;
  --danger: #B42318;
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-card: 16px;
  --shadow-card: 0 4px 18px rgba(26, 45, 35, .045);
  --space-1: 4px; --space-2: 8px; --space-3: 12px;
  --space-4: 16px; --space-6: 24px; --space-8: 32px;
}
```
- 背景网格建议 44px 间距、透明度不超过 4%，不得干扰正文。
- 正文字号 14~16px，页面标题 26~32px，二级标题 18~22px，说明文字 12~14px；中文优先系统无衬线字体，代码用等宽字体。
- 主要操作使用品牌青绿色；AI 相关轻强调使用靛蓝/浅紫；危险操作红色并需确认。
- 卡片采用白底、浅边框、16px 圆角，阴影轻；表格内容区域不要滥用大面积渐变。
- 动画 120~220ms，尊重 prefers-reduced-motion；对比度以 WCAG AA 为目标，颜色不能是唯一状态表达。

## 3. 组件与布局
- 桌面端可采用折叠侧栏+顶部操作区，但必须按业务需求调整；AI 助手优先对话体验，知识库/采购优先高效表格，工作流优先节点图与详情。
- 页面水平内边距：桌面 24~32px，平板 16~24px，移动端 12~16px；内容宽度常规 1200~1440px。
- 按钮：主操作/次操作/危险操作/文字按钮；loading 时禁重复提交；按钮文字必须表达动作。
- 表单：字段标签、必填标识、示例说明、字段级错误；金额显示货币与两位小数。
- 表格：粘性表头可选、分页、筛选、空状态；状态 badge 包含文字；操作栏按权限控制。
- 弹窗：确认操作描述影响范围；删除与拒绝不得仅用 toast 完成。
- 对话：消息与业务卡片视觉区分；引用可定位；工具轨迹默认折叠，避免普通用户被技术细节淹没。
- 工作流：节点状态同时使用文字、图标、颜色；运行中/暂停/失败可区分；图面不可编辑业务规则。

## 4. 响应式断点
`>=1440` 宽桌面；`1024~1439` 普通桌面；`768~1023` 平板；`<768` 移动。侧栏在 `<1024` 可折叠；复杂表格横向滚动且保留关键列；工作流图在手机仅显示步骤列表与详情入口。禁止横向溢出影响全站。

## 5. 视觉验收
- 以真实页面内容验收，不能用参考截图业务文案填充。
- 检查登录、工作台、AI 对话、知识库、采购详情、审批、运行中心的一致性。
- 检查 1440/1280/1024/390 宽度；空/错/加载态；键盘焦点；低对比网格不影响阅读。
- Element Plus 可用于表格/表单/弹窗，但必须用 token 统一主题，不直接交付默认后台模板风格。
