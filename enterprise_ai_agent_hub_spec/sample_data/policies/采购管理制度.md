# 企业采购管理制度（Mock 演示）

> 本制度仅用于 Enterprise AI Agent Hub 本地教学和测试，不代表任何真实企业制度。

## 一、适用范围

本制度适用于办公设备、软件服务及日常行政物资的内部采购申请。申请人必须说明采购用途、数量、预算上限和期望时间，不得拆分申请以规避审批。

## 二、办公电脑标准

办公笔记本电脑单台预算原则上不超过 6000 元。采购前应优先核对可用库存；库存无法满足时，采购人员可从已登记的演示供应商报价中形成候选方案。供应商报价仅作为内部演示数据，不代表实时市场价格。

## 三、审批级别

采购总金额不超过 10000 元时，由部门负责人进行一级审批。采购总金额超过 10000 元时，必须依次完成部门负责人审批和财务审批。审批规则缺失或金额依据不完整时，系统不得自动提交。

## 四、安全与审计

申请人不得审批本人提交的采购申请。所有提交、审批、驳回和采购状态变更都必须记录操作者、时间和结果。系统不得连接真实支付渠道，也不得自动执行外部下单。
