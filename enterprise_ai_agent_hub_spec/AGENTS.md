# Codex 项目执行协议 — Enterprise AI Agent Hub V1.1

## 自动识别阶段指令
收到 `开始 M{n} 阶段任务`、`继续 M{n} 阶段任务`、`验收 M{n} 阶段`（n=0..6）时，无需用户重复输入角色设定或提示词：
1. 阅读本文件、`README.md`、`docs/PRD.md`、`docs/ARCHITECTURE.md`、`docs/IMPLEMENTATION_PLAN.md`、对应 `docs/phases/M{n}.md`，并按任务涉及内容阅读 `docs/API_SPEC.md`、`docs/DATABASE_DESIGN.md`、`docs/FRONTEND_PRD.md`、`docs/UI_DESIGN_SPEC.md`、`docs/AGENT_WORKFLOW.md`、`docs/ACCEPTANCE_CRITERIA.md`。
2. 检查 git 状态、现有代码、已完成阶段的测试证据；有未提交改动先报告并保护，不得覆盖。
3. 检查前置里程碑是否满足 DoD；缺少依赖则停止并列出阻塞项。
4. 给出简短实施计划、变更文件、验证命令，然后在授权的当前阶段内实施，不要求重复确认普通非破坏性开发操作。
5. 实现真实可运行功能，严禁只创建空壳模块；同步实现迁移、测试、前端联动、文档。
6. 实际执行适用的 lint、类型检查、单测、集成测试、构建和必要的启动验证；环境不允许时明确记录未执行项，不可虚构成功。
7. 生成或更新 `docs/PHASE_STATUS.md`（实际状态/日期/证据/遗留问题），输出完成清单、测试结果、风险与下一阶段建议；仅验收通过才标记 DONE。

## 约束
- 仅当前阶段；禁止提前实现 M1-M6 的业务空壳。
- 重要优先级：安全不变量 > 产品需求 > API/数据库/工作流专项规范 > 前端/UI 规范 > 架构建议 > 阶段计划。冲突必须先说明。
- Python 3.12、FastAPI、Pydantic v2、SQLAlchemy 2、Alembic、PostgreSQL、Vue3 + TS + Vite、Chroma、LangGraph、MCP SDK；锁定兼容依赖，先做最小兼容验证。
- 所有金额 Decimal/NUMERIC，库存数量整数；审批、预算、状态转移和授权只能由后端确定性代码控制；申请人不可自审。
- LLM、RAG、MCP 响应一律当作不可信输入；工具参数按 Schema 校验；工具需权限与审计；不得提供任意 shell/SQL 执行能力。
- 仅模拟采购与报价；禁止真实支付/真实下单。写操作不自动重试，必须幂等。
- 必须提供无需真实 Key 的 Mock 模式，Mock 需可复现；不得把 Mock 结果标为实时外部数据。
- 不提交密钥、真实账号或用户隐私数据；日志脱敏，文件上传检查类型/大小。
- 不得未经确认删除已有文件、执行破坏性迁移、清空数据库、修改生产环境或部署生产服务。
- 若发现文档未明确的安全关键选择，先提出最小澄清；普通实现细节按既定规范决策并记录。
